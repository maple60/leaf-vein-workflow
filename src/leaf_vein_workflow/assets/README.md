# Folipuka assistant

`folipuka.png` is the original leaf-tailed dolphin mascot generated with the
built-in image generation tool for this project. The name Folipuka combines
"foliage" and the Japanese floating sound "puka puka".

This is a static, transparent, pixel-art-style concept image, not a hand-drawn
64 × 64 sprite or an animation. The UI scales it to fit 128 × 128 pixels using
nearest-neighbor scaling. It can later be replaced by the user's pixel art
at the same path without changing the guide's behavior.

Use **フォリプカちゃんを表示 / Show Folipuka** in the workflow dock to show or hide it.
Drag the dolphin to move the guide within the current napari window. The
speech bubble follows it and explains the open workflow section in Japanese.
The × button hides the guide; the checkbox shows it again. Positions are kept
while the window is open, but are not saved between app sessions.
